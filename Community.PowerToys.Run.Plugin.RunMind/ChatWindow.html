Workflow orchestration

Independent read-only operations can run concurrently. Writes, approval-gated actions, untrusted MCP calls, and delegated agents run as serialized barriers. Each model turn is a dependency layer. Use the main Stop control to abort the active run: queued operations are marked cancelled and later model-turn layers are not dispatched; an in-flight adapter can stop only as promptly as its underlying operation honors the abort signal. Drag a parallel read-only operation card onto another to prioritize its start order in future independent groups; existing runs and dependency layers are never reordered.
