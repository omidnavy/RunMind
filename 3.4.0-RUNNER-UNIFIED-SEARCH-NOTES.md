# RunMind 3.4.0 — Runner unified search update

- Consolidated launcher providers into one result list; removed the permanently split results/inline-answer pane.
- Added RunMind global query mode and configurable action keyword (default `llm`).
- Global mode contributes RunMind results for each non-empty search while retaining application, file, URL and Calculator results.
- Keyword mode invokes RunMind only for the configured keyword and prompt.
- Search input explicitly uses active theme foreground, caret, selection and selected-text colors.
- Preserved debounced inline generation and cancellation when a newer query arrives.
- Runner settings remain independent of PowerToys Run and Command Palette settings.

Validation: 274 Node regression tests passed. XAML, App.xaml and project XML parsed successfully. A Windows/.NET 10 Release build was not available in this environment and must be run on Windows.


## Runner window and settings UX update

- Added native caption dragging and resizable borders using WPF WindowChrome.
- Added cursor-monitor hotkey targeting (enabled by default), Per-Monitor-V2 DPI awareness and a primary-monitor fallback setting.
- Added PowerToys Run-style result-count-driven window height with a setting to disable automatic resizing.
- Unified one-line field heights and replaced the default ComboBox popup with active-theme surfaces, item states and arrow styling.
- Moved Generation controls into Inline model and conditionally displays Ollama-only or LM Studio-only settings.
- Added configurable 0–100 plugin weights for global-mode result ranking.

Latest portable validation: 280/280 full-suite tests; 25/25 Runner-specific tests. Windows/.NET compilation remains pending.

## Runner window/settings UX correction

- Main Runner window is movable/resizable using WPF WindowChrome.
- Hotkey follows the cursor's monitor by default, with an option to force the primary monitor.
- Per-Monitor-V2 awareness is configured for mixed-DPI displays.
- Automatic result-count-based height is enabled by default and can be disabled for a manually sized window.
- TextBox, PasswordBox and ComboBox dimensions are normalized; ComboBox popup colors are driven by the active theme.
- Generation controls remain within Inline model. Ollama and LM Studio provider-specific fields are conditional, and switching providers invalidates the previous model-discovery list.
- Global mode exposes persisted per-plugin weights (0–100, 50 neutral); they affect global mode only and are scored before the result cap.
- See `docs/RUNNER-WINDOW-UX-AND-RANKING.md` for Windows acceptance checks.

Latest portable validation: 280/280 full-suite tests; 25/25 Runner-specific tests; 57 JavaScript syntax checks; 12 XML/XAML/project/manifest files; 4 JSON files. Windows/.NET build and interactive multi-monitor acceptance remain pending.
