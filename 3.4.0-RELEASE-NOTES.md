# RunMind 3.4.0 — Complete Optional Runner

## Summary

RunMind 3.4.0 adds the complete optional standalone Runner host. Runner is a native Windows launcher with a plugin-based result registry, an inline RunMind LLM experience, a lazy full chat window using the shared RunMind UI and theme system, and independent provider/settings storage. It does not require PowerToys and can be installed or removed independently.

## Launcher plugins

- Applications — bounded Start Menu shortcut discovery and explicit launch.
- Files & Folders — explicit rooted file and folder opening.
- URLs — HTTP/HTTPS opening only.
- Calculator — safe local arithmetic parser with copyable result.
- RunMind — real inline model answers using the same `llm <prompt>` activation style as PowerToys Run.

The launcher has an internal first-party plugin contract. Future RunMind launcher features can register without modifying the shell. Arbitrary third-party plugin code loading is not included.

## RunMind inline model

Runner has an independent Quick/inline provider profile for Ollama's native API and LM Studio's native/OpenAI-compatible APIs. It supports model discovery, model override syntax (`llm > model > prompt`), per-provider keys and custom auth headers, reasoning options, request/discovery timeouts, Ollama keep-alive and CPU thread options, optional generation parameters, and the Nemotron 3.5 Bolt E4B compatibility flag.

The full RunMind chat provider configuration remains separate. Runner inline credentials use Windows DPAPI CurrentUser protection and are not written to the JSON settings file.

## Chat, appearance and host boundary

- Open Chat lazily loads the canonical shared RunMind ChatWindow HTML, CSS and JavaScript.
- Completed or partial inline answers are transferred into the chat transcript rather than being automatically generated a second time.
- The same metadata-discovered RunMind themes and shared appearance preferences are used by both the WPF launcher and embedded chat window.
- Quick Host mode blocks workspace selection, attachments, Full Agent, MCP, Skills, developer tools and System Manager native capabilities.

## Performance and lifecycle

The native launcher and hotkey are initialized without WebView2 startup or provider network requests. Application indexing runs asynchronously. Model discovery/generation starts only for explicit `llm <prompt>` searches, is debounced and cancellable, and has configured time/response limits. WebView2 is initialized only when Open Chat is requested.

Runner includes a configurable global hotkey, tray, single-instance behavior, optional current-user sign-in startup, and independent current-user install/uninstall scripts.

## Compatibility and validation

- Target framework: .NET 10 Windows x64.
- Provider integrations: Ollama native API and LM Studio native/OpenAI-compatible APIs.
- Full solution build and Windows runtime/installer acceptance remain target-machine gates because this packaging environment has no .NET SDK or Windows runtime.
- Portable test, JavaScript syntax and XML/source validation results are recorded in `BUILD-STATUS.md`.

## Not included in 3.4.0

Quick Agentic Mode and system-management tool execution are intentionally not part of this Runner release. They are the next milestone and will be added through one shared restricted Quick Agent Core to Runner, PowerToys Run and Command Palette. Full Agent remains Standalone-only.
