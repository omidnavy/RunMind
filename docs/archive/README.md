# Historical documentation archive

This directory preserves useful engineering history that no longer belongs in the current product guides. Historical reports are retained as records; they are not current setup instructions, current acceptance results, or certification of the 3.4.0 source snapshot.

For current information, start with the [repository README](../../README.md), the [documentation index](../README.md), the [Build and Setup guide](../getting-started/BUILD-AND-SETUP.md), and the [current Build and Validation Status](../project/BUILD-STATUS.md).

## Archive contents

| Directory | Contents |
|---|---|
| [`release-notes/`](release-notes/) | P0–P6 and earlier stabilization release snapshots. |
| [`milestones/`](milestones/) | Historical milestone implementation audits and Windows acceptance checklists. |
| [`validation-reports/`](validation-reports/README.md) | Source, regression, build-fix, and feature validation snapshots, indexed by topic. |
| [`build-fixes/`](build-fixes/) | Intermediate Windows build-fix notes retained for troubleshooting history. |
| [`runner-development/`](runner-development/) | Intermediate Runner UX, search, and handoff implementation notes. |
| [`host-patches/`](host-patches/) | Historical host-specific patch notes. |
| [`stabilization/`](stabilization/) | Earlier 3.3.1 stabilization audit and Windows acceptance records. |
| [`phase-1/`](phase-1/) | Historical integrated Phase 1 validation. |
| [`historical-changelog/`](historical-changelog/CHANGELOG-DETAILED-HISTORY.md) | Detailed implementation history retained behind the concise root changelog. |

Archived reports intentionally preserve their original versions, test counts, paths, commands, and conclusions. Read them in their historical context; prefer current guides and current verification evidence for present-day behavior.
