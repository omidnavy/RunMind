# Historical documentation archive

This directory preserves useful development history that no longer belongs on the current product front page.

**Important:** archived documents describe the source and behavior at the time they were written. They may name old versions, hosts, paths, commands, permissions or test counts. Do not use them as current setup/acceptance instructions. Start with the current [documentation index](../README.md), [Build and setup](../../BUILD-AND-SETUP.md), [Build status](../../BUILD-STATUS.md), and [Feature Matrix](../../FEATURE-MATRIX.md).

## Archive contents

| Directory | Contents |
|---|---|
| `release-notes/` | P0–P6 and earlier stabilization release snapshots. |
| `milestones/` | Historical P0–P6 implementation audits and Windows acceptance checklists. |
| `validation-reports/` | Source/test/build validation reports from previous increments. These are not current build evidence. |
| `build-fixes/` | Intermediate Windows build-fix notes retained for debugging history. |
| `runner-development/` | Intermediate Runner UX and handoff implementation notes. |
| `host-patches/` | Historical host-specific patches. |
| `stabilization/` | Earlier stabilization audit and acceptance records. |
| `phase1/` | Historical integrated Phase 1 validation. |
| `historical-changelog/` | The detailed changelog retained from before the current concise root changelog. |

The archive is intentionally not linked as a long catalogue from the README. Use the filenames or search this directory when investigating a historical change.
