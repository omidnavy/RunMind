# RunMind 3.4.1 — Release notes

RunMind 3.4.1 is a release-metadata alignment and repository-documentation update on top of the 3.4.0 feature release. It does not introduce new application features or intentionally change application behavior.

## Version alignment

| Component | 3.4.1 version metadata |
|---|---|
| Standalone project | `3.4.1` |
| PowerToys Run plugin project and `plugin.json` | `3.4.1` |
| Command Palette project | `3.4.1` |
| Command Palette MSIX project/package identity | `3.4.1.0` |
| Runner project and installer display version | `3.4.1` |
| MCP client identification | `3.4.1` |

The four-part Command Palette package version is the Windows MSIX representation of the three-part product version. The portable regression test checks the project declarations, plugin manifest, MSIX identity, MCP client identification and Runner uninstall metadata together.

## Repository and documentation

- Rebuilt the root README as the GitHub repository front page, with product overview, host/capability descriptions, model/integration support, security boundaries, build instructions and documentation navigation.
- Restored all bundled screenshots to the README. Historical captures are clearly labeled; three launcher captures retain predecessor LocalLLM branding and are not represented as current 3.4.1 screenshots.

- Preserved the 3.4.0 release notes and older historical reports as records of the release and implementation history at that time.

## Host and capability scope

RunMind continues to provide four Windows hosts. Standalone, PowerToys Run and Command Palette host the Full Agent; Runner remains a restricted Quick Host and hands off full workspace tasks to Standalone. Capability details and limits remain as documented in the [feature matrix](../product/FEATURE-MATRIX.md) and [README](../../README.md).

## Validation and release limitations

- The portable Node.js regression suite and static version/link checks are recorded in the accompanying validation report.
- A passing portable test suite does not certify the Windows/.NET build, generated assembly versions, MSIX packaging/signature, WebView2 behavior, host installation or native System Manager actions.
- Complete the Windows validation script and manual acceptance checklists before treating 3.4.1 as a certified binary release. See [Build and validation status](../project/BUILD-STATUS.md).
- Credential protection remains non-uniform: not all Full Chat and shared inline credentials use DPAPI. See [Security and privacy](../security/SECURITY-AND-PRIVACY.md).
