# RunMind 3.5.0 — Release notes

RunMind 3.5.0 adds configurable Agent Toolsets and creates host-specific ZIP archives for publishing the four RunMind hosts as separate GitHub release assets.

## Agent Toolsets

- Added General Assistant, Developer, Researcher, System Administrator and Minimal starting profiles.
- Added group-level enable/disable preferences and individual tool overrides, with editable custom profiles.
- Added a live tool inventory showing group membership, descriptions, individual preferences and whether tools are exposed to the current Agent task.
- Kept System Manager's existing master switch, groups, capabilities, native permission checks and confirmation requirements authoritative. Agent Toolsets cannot enable native capabilities.
- Kept workspace file tools conditional on the selected workspace and its access grant. Toolset preferences can further reduce exposure but cannot grant workspace access.
- Applied the same eligibility check when constructing provider-facing tool definitions and when dispatching tool calls.
- Extended `list_available_tools` with group/profile and configured-versus-exposed reporting while retaining the existing exact exposed-tools array and offset/limit pagination.
- Kept provider-specific request formatting, streaming, and tool-call normalization inside the existing provider adapters. Toolset grouping and reporting do not depend on a particular model provider.

## GitHub release archives

`Build-Release-x64.bat` now creates four separate archives in `Release\GitHub-Releases` after all host builds and required output checks succeed:

- `standalone-3.5.0.zip`
- `runner-3.5.0.zip`
- `powertoysrun-3.5.0.zip`
- `commandpalette-3.5.0.zip`

The PowerToys Run archive includes `Install-RunMind-PowerToys-Run.bat` and the complete plugin build output. The Command Palette archive includes `Install-RunMind-CommandPalette.bat`, its deployment/alias scripts, the signed MSIX, public signing certificate and package manifest. The project `.csproj` is build-time source and is not included in the installable release ZIP. The Runner archive includes its install/uninstall scripts plus the matching Standalone published host as a private companion under `Standalone\win-x64\publish`; its installer places that companion inside the Runner installation directory, so Runner works without a separately installed Standalone and does not overwrite one. Standalone remains packaged as its own published application folder.

The packaging script validates that the four host project versions, PowerToys Run plugin metadata and Command Palette MSIX version agree before producing archives. Packaging does not install any host.

## Version alignment

All four host projects, PowerToys Run plugin metadata, Runner installer metadata and MCP client identification use `3.5.0`. Command Palette uses the required four-part MSIX version `3.5.0.0`.

## Validation

Portable JavaScript regression tests: 346 passed. The Windows .NET 10 build, MSIX signing/package validation, actual archive installation, WebView2 behavior and multi-host runtime acceptance must still be completed on the target Windows installation before claiming binary-release certification.
